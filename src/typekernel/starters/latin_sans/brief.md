# Brief — Latin Sans

Upright neo-grotesque control rhythm: overlap construction (`contour` /
`Drawing` + shared bowl/arch elements), Regular weight, normal counters,
low-to-medium contrast from stem table (`lc` / `uc` / horizontals).

## Typed intent

Optional: declare `BRIEF` / `INTENT` in `system.py` (`typekernel.system.intent`).
Stock starter ships numeric `System` only; add Intent when you fork.

## Quality note

> 结构示例，字形未通过视觉评审，不要当作字形质量范本。
>
> Structural example only — glyph shapes are **not** visually approved; do not treat this starter as a quality reference.

## Non-goals

- No heal / blend / seal.
- No letter builders in the kernel — geometry stays in `glyphs/` + `elements.py`.
